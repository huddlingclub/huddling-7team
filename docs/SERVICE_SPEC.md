# 펭귄 빙하 가계부 — 서비스 기능 정리

> 출처: 와이어플로우 이미지(6단계 상태 화면). 디자인은 이 구조를 기반으로 전체 디벨롭 예정.

## 1. 컨셉

한 달 예산을 **빙하**로, 사용자를 **빙하 위 펭귄**으로 표현한다.
지출이 쌓일수록 빙하가 갈라지고 녹으며, 예산을 넘기면 펭귄이 바다에 빠진다.
숫자 대신 캐릭터 상태로 "지금 얼마나 위험한지"를 직관적으로 전달하는 것이 핵심.

## 2. 화면 구성 (메인 · 단일 화면)

| 영역 | 내용 |
| --- | --- |
| 헤더 | `{M}월의 빙하` 타이틀 + 우측 `목표 1,000,000원` 칩 (월 예산) |
| 히어로 일러스트 | 바다 위 빙하 + 펭귄 + 해. 좌상단 **상태 배지**, 우상단 **말풍선** |
| 요약 카드 | 남은 빙하 금액, `N% 사용`, 단계 눈금 진행바, 하루 권장 지출 |
| 최근 지출 | 리스트 + 총 건수(`N건`), 항목별 삭제(✕) |
| 하단 CTA | `+ 지출 기록하기` (고정 버튼) |

## 3. 빙하 단계 (사용률 기준)

진행바 눈금: `0 · 30% · 50% · 70% · 90% · 파산`

| 단계 | 사용률 | 배지 | 말풍선 | 배지/바 색 | 일러스트 |
| --- | --- | --- | --- | --- | --- |
| 1 | 0 – 30% 미만 | 단단함 | 발밑이 아직 단단해요 | 파랑 | 온전한 빙하, 웃는 펭귄 |
| 2 | 30 – 50% | 금이 감 | 어? 발밑에서 쩍 소리가 났어요 | 파랑 | 금 생김, 놀란 표정 |
| 3 | 50 – 70% | 갈라짐 | 얼음이 갈라지고 있어요 | 주황(앰버) | 균열 확대, 걱정 표정 |
| 4 | 70 – 90% | 조각나는 중 | 조각이 떨어져 나가요! 그만 써요 | 주황 | 빙하 조각 떨어짐, 땀 |
| 5 | 90 – 100% | 위태로움 | 발 디딜 곳이 거의 없어요 | 빨강 | 작은 빙하, 우는 펭귄, 해가 더 뜨거워짐 |
| 6 | 100% 이상 | 파산 | 풍덩! 결국 바다에 빠졌어요 | 빨강 | 빙하 사라짐, 펭귄 물에 빠짐 |

- 단계가 나빠질수록 해가 커지고 주황빛으로 변함 (온도 상승 연출).
- 경계값 포함 여부(예: 정확히 30%)는 확정 필요 → 현재 가정: 하한 포함.

## 4. 요약 카드 계산 로직

```
used        = 이번 달 지출 합계
remaining   = budget - used
usageRate   = used / budget            // 표시: 반올림 정수 %
daysLeft    = 말일 - 오늘 + 1           // 오늘 포함 (11/14 → 17일)
dailyAllow  = floor(remaining / daysLeft / 100) * 100   // 100원 단위 내림
```

검증 (예산 1,000,000원, 남은 17일):
880,000→51,700 · 580,000→34,100 · 400,000→23,500 · 200,000→11,700 · 50,000→2,900 ✅

- 정상: `남은 빙하` / `{remaining}원` / `하루 {dailyAllow}원까지 괜찮아요`
- 초과(remaining < 0): 라벨 `빙하가 다 녹았어요`, 금액 `{|remaining|}원 초과`(빨강), 문구 `오늘은 쓰지 말아요`
- 진행바는 100%에서 꽉 참(초과 시에도 바 길이 고정, 색만 빨강).

## 5. 지출 기록

- 항목 필드: 카테고리, 내용(메모), 금액, 날짜(`M.DD` 표기)
- 카테고리(현재 확인된 것): 식비 · 카페 · 쇼핑 · 교통 — 각 칩 색 구분
- 리스트: 최신순, 금액은 `-9,000원` 형식
- 삭제: 항목 우측 ✕ → 즉시 반영 (실행취소/확인 여부 미정)
- 추가: `+ 지출 기록하기` → 입력 화면/바텀시트 (와이어 미포함)

## 7. 상태 모델 (초안)

```ts
type Category = 'food' | 'cafe' | 'shopping' | 'transport';

interface Expense {
  id: string;
  category: Category;
  title: string;
  amount: number;   // 양수 저장, 표시 시 '-'
  date: string;     // ISO yyyy-mm-dd
}

interface MonthBudget {
  month: string;    // yyyy-mm
  budget: number;
  expenses: Expense[];
}

type GlacierStage = 'solid' | 'cracked' | 'splitting' | 'breaking' | 'critical' | 'bankrupt';
```
